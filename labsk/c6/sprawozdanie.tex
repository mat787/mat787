\vspace{-0.5em}
Celem ćwiczenia była konfiguracja zapory (Windows/Unix), podłączenie VPS
w Azure do sieci ZeroTier ADM, uruchomienie kontenera Docker z usługą WWW
oraz montaż udziału SMB z laptopa. Pracę wykonano na stacji \texttt{c2}.

\section{Konfiguracja zapory internetowej}

\subsection{Unix -- Azure NSG (\texttt{gen-vps})}

Skrypt \texttt{gen-vps} (\texttt{az/nsg -a}) tworzy grupę \texttt{LabSK-NSG}
i reguły zapory w chmurze.

\begin{lstlisting}
drapich@c2 ~ % gen-vps
Kreacja grupy bezpieczeństwa sieci LabSK-NSG in LabSK ...
Nowa grupa NSG LabSK-NSG ...
Dodanie reguły AllowSSHInbound (22 Tcp) ...
Dodanie reguły AllowICMPInbound (* Icmp) ...
Dodanie reguły AllowZeroTierInbound (9993 Udp) ...
Dodanie reguły AllowHTTPInbound (80 Tcp) ...
Dodanie reguły AllowHTTPSInbound (443 Tcp) ...
Dodanie reguły AllowSMBInbound (445 Tcp) ...
Grupa LabSK-NSG gotowa
\end{lstlisting}

\subsection{Konfiguracja firewalla na Windowsie}

PowerShell (admin): reguły SMB TCP 445, profil \texttt{Private}.

\begin{lstlisting}
PS> New-NetFirewallRule -DisplayName "LabSK SMB In" -Direction Inbound -Protocol TCP -LocalPort 445 -Action Allow -Profile Private
Enabled=True  Direction=Inbound  Action=Allow  Profile=Private
PS> New-NetFirewallRule -DisplayName "LabSK SMB Out" -Direction Outbound -Protocol TCP -RemotePort 445 -Action Allow -Profile Private
Enabled=True  Direction=Outbound  Action=Allow  Profile=Private
PS> Enable-NetFirewallRule -DisplayGroup "File And Printer Sharing"
PS> Enable-NetFirewallRule -DisplayGroup "Network Discovery"
PS> Get-NetFirewallRule -DisplayName "LabSK SMB*" | Format-Table DisplayName,Enabled,Direction,Action
LabSK SMB In     True   Inbound  Allow
LabSK SMB Out    True  Outbound  Allow
\end{lstlisting}

\textit{Po \texttt{Enable-NetFirewallRule} brak komunikatu --- reguły grup włączone.
Opcjonalny dowód: \texttt{Get-NetFirewallRule -DisplayGroup "File And Printer Sharing" | ? Enabled -eq True | Select -First 1 Enabled}.}

\subsection{Udostępnienie SMB (macOS / montaż na VPS)}

użytkownik \texttt{mat}). Montaż na VPS: \texttt{//10.80.108.105/vps}.

\section{Usługa SMB (\texttt{mount-smb})}

Udział SMB zamontowano na VPS w \texttt{\TY/vps}; widoczne pliki z laptopa.

\begin{lstlisting}
drapich@c2 ~ % ssh $vps ls vps
plik.txt  test
drapich@c2 ~ % ssh $vps "which mount-smb"
/home/drapich/bin/mount-smb
\end{lstlisting}

\section{Podsumowanie}

\begin{itemize}
\item Zapora Windows: \texttt{LabSK SMB In/Out} (TCP 445, PowerShell).
\item Zapora Unix/chmura: \texttt{LabSK-NSG} (SSH 22, ICMP, ZT 9993, HTTP/S 80/443, SMB 445).
\item ZeroTier ADM: VPS \texttt{10.80.108.10/24} na \texttt{ztu7tkwebg}.
\item Docker + WWW: \texttt{gen-kont} $\rightarrow$ dwa razy \texttt{HTTP/1.1 200 OK}.
\item SMB: \texttt{plik.txt}, \texttt{test} w \texttt{\TY/vps} na VPS.
\end{itemize}

\section*{Do uzupełnienia przed oddaniem}

\begin{enumerate}
\item \textbf{gen-vps} --- reszta logu (\texttt{cat \TY/.vps}, klucz SSH) --- opcjonalnie.
\item \textbf{gen-fw} --- opcjonalnie \texttt{ufw status} na VPS.
\item \textbf{ZeroTier} --- \texttt{zerotier-cli listnetworks} (status \texttt{OK}).
\item \textbf{Docker} --- \texttt{ssh \$vps "sudo docker ps"}.
\item \textbf{Schemat ADM.svg} --- poprawić IP VPS na \texttt{.10}.
\item \textbf{Ping ADM} --- \texttt{ping vps.adm} z c2 lub MacBooka (jeśli \texttt{/etc/hosts}).
\end{enumerate}
