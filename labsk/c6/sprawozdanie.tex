Celem ćwiczenia była konfiguracja zapory (Windows/Unix), podłączenie VPS
w Azure do sieci ZeroTier ADM, uruchomienie kontenera Docker z usługą WWW
oraz montaż udziału SMB z laptopa. Pracę wykonano na stacji \texttt{c2}.

blokuje ruch przychodzący, przepuszcza ZeroTier (UDP 9993) i SSH z interfejsu ZT.

\subsection{Konfiguracja firewalla na Windowsie}

W PowerShell (konto administratora) skonfigurowano zaporę pod udostępnienie SMB:
reguły \texttt{LabSK SMB In/Out} dla portu TCP 445 (profil \texttt{Private}),
oraz włączono \texttt{File And Printer Sharing} i \texttt{Network Discovery}.

\begin{lstlisting}
PS C:\Users\Matylda> New-NetFirewallRule -DisplayName "LabSK SMB In" -Direction Inbound -Protocol TCP -LocalPort 445 -Action Allow -Profile Private
DisplayName : LabSK SMB In
Enabled     : True
Profile     : Private
Direction   : Inbound
Action      : Allow
PrimaryStatus : OK

PS C:\Users\Matylda> New-NetFirewallRule -DisplayName "LabSK SMB Out" -Direction Outbound -Protocol TCP -RemotePort 445 -Action Allow -Profile Private
DisplayName : LabSK SMB Out
Enabled     : True
Profile     : Private
Direction   : Outbound
Action      : Allow
PrimaryStatus : OK

PS C:\Users\Matylda> Enable-NetFirewallRule -DisplayGroup "File And Printer Sharing"
PS C:\Users\Matylda> Enable-NetFirewallRule -DisplayGroup "Network Discovery"
PS C:\Users\Matylda> Get-NetFirewallRule -DisplayName "LabSK SMB*" | Format-Table DisplayName, Enabled, Direction, Action

DisplayName   Enabled Direction Action
-----------   ------- --------- ------
LabSK SMB In     True   Inbound  Allow
LabSK SMB Out    True  Outbound  Allow
\end{lstlisting}

Reguły są aktywne (\texttt{Enabled: True}); ruch SMB (port 445) dozwolony
w sieci prywatnej --- wymagane do montażu udziału SMB z serwera VPS.

Udział SMB zamontowano na VPS w \texttt{\TY/vps}; widoczne pliki z laptopa.

\section{Podsumowanie}

\begin{itemize}
\item Zapora Windows: reguły \texttt{LabSK SMB In/Out} (PowerShell, TCP 445).
\item Zapora Unix: \texttt{gen-fw} (UFW) --- \textit{brak logu wykonania}.
\item ZeroTier ADM: VPS \texttt{10.80.108.10/24} na \texttt{ztu7tkwebg}.
\item Docker + WWW: \texttt{gen-kont} $\rightarrow$ dwa razy \texttt{HTTP/1.1 200 OK}.
\item SMB: \texttt{plik.txt}, \texttt{test} w \texttt{\TY/vps} na VPS.
\end{itemize}

\section*{Do uzupełnienia przed oddaniem}

\begin{enumerate}
\item \textbf{gen-vps} --- log z \texttt{az/nsg} i \texttt{cat \TY/.vps}.
\item \textbf{gen-fw} --- uruchomić i wkleić \texttt{ufw status}.
\item \textbf{ZeroTier} --- \texttt{zerotier-cli listnetworks} (status \texttt{OK}).
\item \textbf{Docker} --- \texttt{ssh \$vps "sudo docker ps"}.
\item \textbf{Schemat ADM.svg} --- poprawić IP VPS na \texttt{.10}.
\item \textbf{Ping ADM} --- \texttt{ping vps.adm} z c2 lub MacBooka (jeśli \texttt{/etc/hosts}).
\end{enumerate}
