\section*{Zadania i dowody wykonania}

\textbf{1. Generacja VPS} --- skrypt \texttt{gen-vps} tworzy Archlinux w Azure, zapisuje DNS w \texttt{\textasciitilde/.vps}, mapuje \texttt{vps} w \texttt{/etc/hosts}.
\begin{lstlisting}
$ gen-vps
74.248.150.53 vps
$ cat ~/.vps
drapich.polandcentral.cloudapp.azure.com
\end{lstlisting}

\textbf{2. Konfiguracja VPS} --- \texttt{config-vps}: zsh, \texttt{~/bin/ipb}, gemini-cli, dołączenie do ADM.
\begin{lstlisting}
$ config-vps
200 join OK
$ ssh vps "ipb a"
eth0 ... 10.0.0.4/24
ztu7tkwebg ... 10.80.108.71/24
$ ssh vps 'pacman -Q gemini-cli'
gemini-cli 1:0.45.2-1
\end{lstlisting}

\textbf{3. Sieć VPN/GAN (ZeroTier ADM)} --- VPS i laptop w sieci prywatnej; stacja sX po publicznym IP.
\begin{lstlisting}
$ ssh vps 'sudo zerotier-cli listnetworks'
... ADM ... OK ... 10.80.108.71/24
$ ping -c1 vps
64 bytes from 74.248.150.53
$ ping -c1 vps.adm    # MacBook
64 bytes from 10.80.108.71
\end{lstlisting}

\textbf{4. Serwis WWW (nginx)} --- \texttt{config-www} instaluje i uruchamia nginx.
\begin{lstlisting}
$ curl -I http://vps
HTTP/1.1 200 OK
Server: nginx/1.30.2
$ curl http://vps | head -1
<!DOCTYPE html>
\end{lstlisting}
