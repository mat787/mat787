\section{Skryptowa konfiguracja serwera w chmurze}

\subsection{Generacja VPS -- \texttt{gen-vps}}

Skrypt tworzy maszynę Archlinux w Azure, zapisuje DNS w \texttt{\TY/.vps}
i mapuje nazwę \texttt{vps} na publiczny adres IP w \texttt{/etc/hosts}.

\begin{lstlisting}
drapich@s2 ~ % gen-vps
ResourceGroup  PowerState   PublicIpAddress  Fqdns
LabSK          VM running   74.248.150.53    drapich.polandcentral.cloudapp.azure.com
74.248.150.53 vps
drapich@s2 ~ % cat ~/.vps
drapich.polandcentral.cloudapp.azure.com
drapich@s2 ~ % grep vps /etc/hosts
74.248.150.53 vps
\end{lstlisting}

\subsection{Konfiguracja VPS -- \texttt{config-vps}}

Skrypt instaluje \texttt{zsh}, agenta \texttt{gemini-cli}, tworzy \texttt{~/bin/ipb}
oraz dołącza serwer do sieci ZeroTier ADM.

\begin{lstlisting}
drapich@s2 ~ % config-vps
200 join OK
drapich@s2 ~ % ssh vps "echo $SHELL"
/usr/bin/zsh
drapich@s2 ~ % ssh vps "ipb a"
lo         UNKNOWN  127.0.0.1/8 ...
eth0       UP       10.0.0.4/24 ...
ztu7tkwebg UNKNOWN  10.80.108.71/24 ...
drapich@s2 ~ % ssh vps 'pacman -Q gemini-cli'
gemini-cli 1:0.45.2-1
\end{lstlisting}

\subsection{Sieć VPN/GAN -- ZeroTier ADM}

Sieć prywatna ADM (\texttt{8d1c312afa9a3adc}, \texttt{10.80.108.0/24}).
VPS i laptop w ADM; stacja sX łączy się z VPS po publicznym IP.

\begin{lstlisting}
drapich@s2 ~ % ssh vps 'sudo zerotier-cli listnetworks'
200 listnetworks 8d1c312afa9a3adc ADM ... OK PRIVATE ztu7tkwebg 10.80.108.71/24
drapich@s2 ~ % ping -c1 vps
64 bytes from vps (74.248.150.53): icmp_seq=1 ttl=46 time=12.7 ms
mat@mat ~ % ping -c1 vps.adm
64 bytes from 10.80.108.71: icmp_seq=0 ttl=64 time=22.3 ms
mat@mat ~ % ping -c1 lap.adm
64 bytes from 10.80.108.105: icmp_seq=0 ttl=64 time=0.103 ms
\end{lstlisting}

\section{Konfiguracja serwisu WWW}

\subsection{Nginx -- \texttt{config-www}}

Wybrany serwis: WWW. Skrypt instaluje i uruchamia \texttt{nginx} na VPS.
Port 80 otwarty w NSG \texttt{LabSK-NSG}.

\begin{lstlisting}
drapich@s2 ~ % config-www
Created symlink ... nginx.service
drapich@s2 ~ % ssh vps 'systemctl is-active nginx'
active
drapich@s2 ~ % curl -I http://vps
HTTP/1.1 200 OK
Server: nginx/1.30.2
drapich@s2 ~ % curl http://vps | head -3
<!DOCTYPE html>
<html>
<head>
\end{lstlisting}
